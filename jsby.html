API 设置

网页版没有服务器，对话由 DeepSeek API 生成，页面直接调用 api.deepseek.com。Key 只存在这台设备的浏览器里，不写进页面代码。

填好 Key 后点「探测连接」，验证 Key 和网络是否连通，并拉取可用模型。
探测请求的是模型列表接口，只验证连通性，不发对话、不产生对话费用。没有 Key 去 platform.deepseek.com 申请。
探测成功后，这里会换成接口实际返回的可用模型列表，再由你自己选。
列表里没有想要的模型时，在这里直接填模型 ID；留空则用上面的选择。
